# 粤普同传 Windows 使用说明

使用轻量安装包时，首次打开可下载或导入基础模型。以后可通过「设置 → 模型管理」修复或删除模型，并按需准备 pro 复核和文件人声分离。模型默认保存在 `%LOCALAPPDATA%\YuePuTranslate\models`。完整离线安装包已附带全部模型。

首次拉取源码后，安装 Python 3.12 x64，再双击根目录的 `Initialize-YuePu.cmd` 选模型。文字翻译选 T，基础收音和双向播报选 F，带句末复核选 P。完成后双击 `Start-YuePu.cmd`。新用户的初始模式依据已安装的模型选择，已有的首选项优先。窗口打开即可输入。短句和实时字幕共用 Hy-MT2 服务。启用麦克风自动播报时，软件在识别出文字后开始准备目标音色。

文字、收音和打开音频共用一个输入区。

普通话译音使用 MeloTTS INT8。旧环境升级后先运行 `python experiments/offline-poc/prepare_models.py mandarin`，将固定模型和字典准备到 `models/tts-zh/`。旧 Huayan 音色缓存不自动删除，也不会继续用于运行或新安装数据。

基础识别已改用 WenetSpeech-Yue U2++ CTC；旧环境还需运行 `python experiments/offline-poc/prepare_models.py asr`，准备 `models/asr-wenet/`。它不提供自动语种判断，请主动选择粤普方向；短音频和其他语言音频仍可能误识别。

通过“设置 → 外观”切换使用中性色的深色和浅色主题，下次启动会记住选择。主题同时应用于字幕、输入框、状态提示及设置对话框。

1. 在输入区左下的方向菜单选择粤语 → 普通话或普通话 → 粤语。输入文字后点击“翻译”或按 Ctrl + Enter。
2. 通过输入区的“收音选项”菜单选择音源、识别模式、灵敏度和播报。面对面交流选麦克风，翻译电脑播放内容选设备播放声音。
3. 开始收音后，pro 模式先显示暂定原文和粗略译文，再在停顿后复核原文并修正译文。flash 使用轻量实时处理。再次点击收音按钮会停止采集并处理末尾，也可按 Esc 取消未完成处理。已有字幕继续保留。
4. 原文与译文左右配对。向上滚动可以回看，返回最新位置后继续跟随。平滑滚动可在设置中调整。
5. 翻译结果按会话自动保存在本机。点击左侧记录可以回看或继续翻译，重新打开应用后仍可从这里找到会话。空闲时可点“新会话”开始另一组翻译。确认清空某个会话的字幕后，也会从历史中移除该会话。需要单独的字幕文件时，使用导出功能。

设备声音模式录制 Windows 默认输出设备的混合声音。请确认视频正在该设备播放；切换输出设备后应停止并重新开始采集。收音期间禁止播放译音，停止后可以播放选中内容。

手机外放视频、电脑负责翻译时，请选择“麦克风”，并确认 Windows 默认输入是实际使用的麦克风。

输入区下拉菜单中的收音灵敏度提供两档，选择后自动保存，停止收音后可切换。

- **标准（默认）**：适合嘈杂环境，使用更严格的人声判定，不放大检测器的轻声输入；较轻的短句可能漏听。
- **灵敏**：适合手机外放、轻声和短句，仅对检测器输入做最多 8 倍增益，正式识别仍使用原始音频；更容易收到背景音乐或旁人讲话。

两档均用于麦克风和设备声音的 pro/flash 实时收音，不改变音频文件处理。旁人讲话和带人声的音乐也可能被识别，两档都不能只锁定指定说话人。距离、混响和麦克风降噪仍可能影响效果。

文本输入不超过 120 字符；flash 模式文件输入为不超过 15 秒的 WAV。

flash 模式使用基础识别模型，首轮音频窗口约 0.8 秒，之后约每 0.64 秒尝试更新，不等待翻译或播报完成。实际出现字幕的时间还取决于音量、语速和电脑性能。连续讲话约 8 秒后会确认当前短段并另起一条；这能限制识别和翻译的积压，不代表已核对文字准确。pro 的草稿也会提前显示，但沿用原段落检测与断句，粗略译文可先显示，确认译文需要等待停顿和大模型复核。

正文颜色的文字为已固定前文，灰色文字为仍可修订的末尾，文字状态也会说明确认情况。原文更新时保留已有译文，只更新暂定部分；固定短句只翻译一次。暂定译文可能暂时落后于原文，随后局部替换；停顿或分段确认后整条显示为正文颜色。

## 设置与文件位置

“设置 → 首选项…”可保存默认模式（pro 或 flash）、方向、音源、收音灵敏度、自动播报、字号、平滑滚动、数字读法及文件人声分离选项。首次使用标准灵敏度。按 F 初始化后首次收音使用 flash，按 P 初始化后首次收音使用 pro。旧首选项缺少灵敏度时补为标准，其他设置保留。原段落修订首选项会按 pro 解释，用户显式保存的 flash 仍会恢复。

“文件位置”可设置临时缓存和字幕导出目录。缓存默认使用系统临时目录，正常任务结束后清理。会话历史保存在 `%LOCALAPPDATA%/YuePuTranslate/history.sqlite3`，只包含字幕文字、语种、时间和确认状态等信息。更换目录只影响后续的临时缓存和字幕导出。模型位置仍由 `YUEPU_DATA_DIR` 指定。目录不可写时，可在这里清空以恢复默认位置或选择其他目录，再重试翻译。

## 联网增强

打开“设置 → 联网设置…”，填写自己的百炼密钥及对应地域，勾选启用并保存。pro 上传检查点或句末复核音频与确认后待翻译文字，flash 在本地识别后仅上传翻译文字。两种音源和文件均可使用，pro 仍需本地大模型用于失败回退。默认关闭，每次启动都须重新开启。费用、上传范围、加密记住密钥及连接测试见 [联网增强说明](online.md)。

## pro（原段落修订）

按 README 准备 `song-asr-large`，在“收音选项”中选择 pro。约 2 秒的段落停顿阈值、2 秒前导、8 秒上下文及 2 秒重叠、连续约 15 秒分段上限均沿用原段落方案。实时人声触发针对短句和轻声做了调整。

轻量模型在首个约 0.8 秒音频窗口后尝试显示草稿，之后约每 0.64 秒更新。草稿始终暂定，原文未确认时即可显示粗略译文；等待翻译或复核时可以继续显示后续原文。大模型在原有检查点保留较早音频的识别文字；检查点不另起一行，粗略译文不会自动播报。停顿或原分段上限到达后复核当前段落，再固定原文、修正译文并播报；已确认记录不会重写或重新翻译。

粗译约每 2.5 秒至多重新生成一次，待处理草稿只保留最新一份；原文持续变化时允许显示稍早的粗译。状态和灰色文字说明其尚未确认，迟到粗译不会覆盖已确认原文对应的最终译文。

实际速度取决于模型计算和排队，采样节奏不是延迟承诺。轻量识别和复核都可能有错；复核没有有效文字时保留未确认状态，不用轻量猜测充当确认。

再次点击收音按钮会停止采集并补完已收到的音频。短时积压时优先处理确认任务，部分草稿可能跳过。持续积压达到上限时，软件会停止接收新音频，把已接纳的部分送去识别和翻译。会话历史和文本导出均包含收音中断位置。将鼠标停在收音按钮上，可以查看上次采集的缓冲峰值和最长等待。按 Esc 可取消待处理任务并保留已有字幕，未完成的文字会标为暂定或已取消。设备声音模式只显示字幕。

pro 支持最多 10 分钟 / 100 MB 的 MP3、WAV、FLAC、OGG。可在“设置 → 首选项… → 阅读与播报”启用文件人声分离。文件不自动播报译音。

数字读音模式需要明确选择金额或逐位号码，只调整合成输入，不改变显示译文；混合语境和重要数字仍需人工核对。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 无法启动或依赖缺失 | 在 PowerShell 使用 README 的模块命令启动，查看报错；确认使用 Python 3.12 x64 和本项目环境 |
| 提示临时缓存不可写 | 在“设置 → 首选项… → 文件位置”清空缓存目录以使用系统临时目录，或选择可写目录，再重试 |
| 提示模型或运行程序不完整 | 轻量版从「设置 → 模型管理」下载或修复模型。源码可运行根目录的 `Initialize-YuePu.cmd`。若已下载，请核对当前模型目录和 `YUEPU_DATA_DIR` |
| 音源已打开，提示等待音频包 | 设备约 3 秒没有交付数据。检查 Windows 默认设备和播放来源，恢复交付后会继续收音。全零的静音音频也算正常交付 |
| 没有麦克风输入 | 检查 Windows 麦克风权限和默认输入设备 |
| 回放译音被再次识别 | 使用耳机，或在「设置 → 首选项 → 常规 → 收音与播报」开启扬声器播报时暂停拾音。该选项默认关闭，仅在麦克风自动播报时按设备播放时间跳过重叠声音，对方同时插话也会被跳过。房间余响和设备实际延迟会影响效果 |
| 顶部显示「本地逐句翻译」 | 系统明确拒绝了本机服务连接。短句和 flash 仍可使用离线 Hy-MT2，逐句启动会稍慢。pro 的复核服务需要允许本机 127.0.0.1 通信；允许后重启应用即可重试常驻模式 |
| 字幕暂时不刷新 | 先检查是否正在回看旧字幕，再查看状态栏的识别与翻译耗时 |
| 歌词大量错词 | 确认选了 pro 及正确方向；可用人声分离处理文件作对照，当前仅有少量歌曲验证 |
| 歌曲模型不完整 | 从「模型管理」准备 pro 复核。开启文件人声分离时，也需要准备对应的模型组 |

采集和模型调用失败会显示状态。提交问题时附操作步骤和匿名错误提示即可，不要上传完整私人对话。

正常点击「结束收音」后，软件等待已接纳音频和采集端的结束确认。采集端传包的总等待上限为 12 秒，超过限时会标出可确认的边界，之后的识别和翻译另行收尾。按 Esc 或关闭窗口会取消余下任务，并保存截止时已提交给窗口的终译和中断位置。复制、导出和重新打开的历史会标出尚待复核的译文，以及仍对应旧原文的草稿。

实时字幕与自动播报分别处理，积压时优先保留字幕。待播队列装满会提示哪部分需要手动重播。输出设备失败会停止当前任务的译音，下一次手动重播可以重新尝试。切换会话会结束旧会话的播放。旧稿手动重播只读已固定的前文，没有固定内容时「播报」按钮不可用。较长的粤语译音会按句合成，单个分句达到模型上限时会提示可能读不完整。
