# Windows 使用说明

按根目录 README 准备 Python 环境和模型后，双击 `Start-YuePu.cmd`，等待模型加载及预热完成。

1. 选择方向：粤语 → 普通话，或普通话 → 粤语。
2. 选择声音来源：面对面交流选麦克风；翻译电脑播放内容选设备播放声音。
3. 默认选择“会话（实时字幕）”，点击开始。原文随说话持续更新，译文稍后显示；暂定文字可能自动校正，停顿后确认。再次点击收音按钮会停止采集并处理末尾；独立“停止”按钮或 Esc 取消未完成处理，已有字幕继续保留。
4. 原文与译文左右配对。向上滚动可以回看，返回最新位置后继续跟随。平滑滚动可在界面中调整。
5. 退出前按需导出字幕；会话不会自动恢复。

设备声音模式录制 Windows 默认输出设备的混合声音。请确认视频正在该设备播放；切换输出设备后应停止并重新开始采集。收音期间禁止播放译音，停止后可以播放选中内容。

文本输入不超过 120 字符；会话模式文件输入为不超过 15 秒的 WAV。

会话模式使用基础识别模型，首轮音频窗口约 0.8 秒，之后约每 0.64 秒尝试更新，不等待翻译或播报完成。实际出现字幕的时间还取决于音量、语速和电脑性能。连续讲话约 8 秒后会确认当前短段并另起一条；这能限制识别和翻译的积压，不代表已核对文字准确。需要长段上下文复核时可选择“段落修订（实验）”，等待通常更长。

亮色文字为已固定前文，较浅文字为仍可修订的末尾。原文更新时保留已有译文，只更新暂定部分；固定短句只翻译一次。暂定译文可能暂时落后于原文，随后局部替换；停顿或分段确认后整条显示为亮色。

## 联网增强

点击顶部“联网设置”，填写自己的百炼密钥及对应地域，勾选启用并保存。联网增强自动使用段落修订，同样支持两种声音来源、歌曲文件和文字输入；仍需准备本地段落模型用于失败回退。默认关闭，每次启动都须重新开启。费用、上传范围、加密记住密钥及连接测试见 [联网增强说明](online.md)。

## 段落修订（实验）

按 README 额外准备 `song-asr-large`，加载基础模型后，在“识别模式”中选择“段落修订（实验）”。选择麦克风或设备播放声音，然后开始收音。同一段发言持续更新原记录，计算窗口滚动时不新增一行。人声停顿后复查近期识别、断句和译文，再确认本段；仅确认后才自动播报。设备收音期间始终只显示字幕。

持续长讲话会逐步固定连续两次一致的完整短句，保留末尾继续修订。已固定的文字及译文不再改写或重新翻译；实时识别保留最多 8 秒上下文及 2 秒衔接，连续约 15 秒后另起一条，已有记录继续保留。只保留最新待处理草稿，避免反复处理过时版本。停顿和文本稳定都只是自动判断，唱腔、纯伴奏和重叠人声仍可能造成错漏、重复或误判。

再次点击收音按钮会停止采集并等待末尾确认；点击独立“停止”或按 Esc 则取消等待，未确认记录标为暂定，已确认内容保留。处理太慢时合并过时的暂定更新；如果句末或上下文检查点也积压，则明确停止收音，不无限排队。

“打开歌曲”支持不超过 10 分钟 / 100 MB 的 MP3、WAV、FLAC、OGG（单/双声道，8–192 kHz）。默认直接识别原始音频。如需高质量处理，额外准备 `song-separator`，在“设置 → 高质量选项”勾选人声分离，然后打开歌曲。分离期间显示进度，可随时取消；该选项不作用于实时收音，也不会自动保存人声文件。文件处理不自动播报译音。

数字读音模式需要明确选择金额或逐位号码，只调整合成输入，不改变显示译文；混合语境和重要数字仍需人工核对。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 无法启动或依赖缺失 | 在 PowerShell 使用 README 的模块命令启动，查看报错；确认使用 Python 3.12 x64 和本项目环境 |
| 提示模型不完整 | 检查准备脚本和应用的 `YUEPU_DATA_DIR` 一致，重新准备缺少的组件 |
| 没有收到设备声音 | 检查 Windows 默认输出、来源选择及播放状态；切换设备后重新开始 |
| 没有麦克风输入 | 检查 Windows 麦克风权限和默认输入设备 |
| 回放译音被再次识别 | 交流时使用耳机，避免扬声器声音进入麦克风 |
| 字幕暂时不刷新 | 先检查是否正在回看旧字幕，再查看状态栏的识别与翻译耗时 |
| 歌词大量错词 | 确认选了段落修订及正确方向；可用人声分离处理文件作对照，当前仅有少量歌曲验证 |
| 歌曲模型不完整 | 额外运行 README 的 `song-asr-large` 准备命令；高质量文件处理还需要 `song-separator` |

采集和模型调用失败会显示状态。提交问题时附操作步骤和匿名错误提示即可，不要上传完整私人对话。
