# Windows 使用说明

按根目录 README 准备 Python 环境和模型后，双击 `Start-YuePu.cmd`。在左侧控制台点击“加载离线模型”，等待加载及预热完成后，同一位置会显示收音按钮。

普通话译音使用 MeloTTS INT8。旧环境升级后先运行 `python experiments/offline-poc/prepare_models.py mandarin`，将固定模型和字典准备到 `models/tts-zh/`。旧 Huayan 音色缓存不自动删除，也不会继续用于运行或新安装数据。

基础识别已改用 WenetSpeech-Yue U2++ CTC；旧环境还需运行 `python experiments/offline-poc/prepare_models.py asr`，准备 `models/asr-wenet/`。它不提供自动语种判断，请主动选择粤普方向；短音频和其他语言音频仍可能误识别。

右上角“深色 / 浅色”可随时切换外观，下次启动会记住选择。主题同时应用于字幕、输入框、状态提示及设置对话框；切换时保留本次字幕、选中记录和回看位置。小窗口中的左侧设置可独立滚动，开始和停止按钮固定在底部。

1. 选择方向：粤语 → 普通话，或普通话 → 粤语。
2. 选择声音来源：面对面交流选麦克风；翻译电脑播放内容选设备播放声音。
3. 默认选择 pro（原段落修订），点击开始，轻量模型先显示暂定原文和粗略译文，停顿后由较大模型复核再确认原文、修正译文并播报。flash 仍保留原轻量处理。再次点击收音按钮会停止采集并处理末尾；独立“停止”按钮或 Esc 取消未完成处理，已有字幕继续保留。
4. 原文与译文左右配对。向上滚动可以回看，返回最新位置后继续跟随。平滑滚动可在界面中调整。
5. 退出前按需导出字幕；会话不会自动恢复。

设备声音模式录制 Windows 默认输出设备的混合声音。请确认视频正在该设备播放；切换输出设备后应停止并重新开始采集。收音期间禁止播放译音，停止后可以播放选中内容。

手机外放视频、电脑负责翻译时，请选择“麦克风”，并确认 Windows 默认输入是实际使用的麦克风。

主界面的“收音灵敏度”提供两档，选择后自动保存，停止收音后可切换：

- **标准（默认）**：适合嘈杂环境，使用更严格的人声判定，不放大检测器的轻声输入；较轻的短句可能漏听。
- **灵敏**：适合手机外放、轻声和短句，仅对检测器输入做最多 8 倍增益，正式识别仍使用原始音频；更容易收到背景音乐或旁人讲话。

两档均用于麦克风和设备声音的 pro/flash 实时收音，不改变音频文件处理。旁人讲话和带人声的音乐也可能被识别，两档都不能只锁定指定说话人。距离、混响和麦克风降噪仍可能影响效果。

文本输入不超过 120 字符；flash 模式文件输入为不超过 15 秒的 WAV。

flash 模式使用基础识别模型，首轮音频窗口约 0.8 秒，之后约每 0.64 秒尝试更新，不等待翻译或播报完成。实际出现字幕的时间还取决于音量、语速和电脑性能。连续讲话约 8 秒后会确认当前短段并另起一条；这能限制识别和翻译的积压，不代表已核对文字准确。pro 的草稿也会提前显示，但沿用原段落检测与断句，粗略译文可先显示，确认译文需要等待停顿和大模型复核。

正文颜色的文字为已固定前文，灰色文字为仍可修订的末尾，文字状态也会说明确认情况。原文更新时保留已有译文，只更新暂定部分；固定短句只翻译一次。暂定译文可能暂时落后于原文，随后局部替换；停顿或分段确认后整条显示为正文颜色。

## 设置与文件位置

顶部“设置”可保存默认模式（pro 或 flash）、方向、音源、收音灵敏度、自动播报、字号、平滑滚动、数字读法及文件人声分离选项。首次默认为 pro、标准灵敏度；旧首选项缺少灵敏度时补为标准，其他设置保留。原段落修订首选项会按 pro 解释，用户显式保存的 flash 仍会恢复。

“文件位置”可设置临时缓存和字幕默认保存目录。缓存默认使用系统临时目录，正常任务结束后清理；字幕仅在手动导出时保存。更换位置不迁移或删除旧文件、不移动模型、不自动保存录音和会话。模型位置仍由 `YUEPU_DATA_DIR` 指定。目录不可写时可在这里清空以恢复默认位置或选择其他目录，保存后重新加载模型。

## 联网增强

点击顶部“联网设置”，填写自己的百炼密钥及对应地域，勾选启用并保存。联网增强保留当前模式：pro 上传检查点/句末复核音频与确认后待翻译文字，flash 在本地识别后仅上传翻译文字。两种音源和文件均可使用；pro 仍需本地大模型用于失败回退。默认关闭，每次启动都须重新开启。费用、上传范围、加密记住密钥及连接测试见 [联网增强说明](online.md)。

## pro（原段落修订）

按 README 准备 `song-asr-large`，加载基础模型后选择 pro。约 2 秒的段落停顿阈值、2 秒前导、8 秒上下文及 2 秒重叠、连续约 15 秒分段上限均沿用原段落方案；实时人声触发针对短句和轻声做了调整。

轻量模型在首个约 0.8 秒音频窗口后尝试显示草稿，之后约每 0.64 秒更新。草稿始终暂定，原文未确认时即可显示粗略译文；等待翻译或复核时可以继续显示后续原文。大模型在原有检查点保留较早音频的识别文字；检查点不另起一行，粗略译文不会自动播报。停顿或原分段上限到达后复核当前段落，再固定原文、修正译文并播报；已确认记录不会重写或重新翻译。

粗译约每 2.5 秒至多重新生成一次，待处理草稿只保留最新一份；原文持续变化时允许显示稍早的粗译。状态和灰色文字说明其尚未确认，迟到粗译不会覆盖已确认原文对应的最终译文。

实际速度取决于模型计算和排队，采样节奏不是延迟承诺。轻量识别和复核都可能有错；复核没有有效文字时保留未确认状态，不用轻量猜测充当确认。

再次点击收音按钮会停止采集并等待末尾确认；独立“停止”或 Esc 取消等待。过时草稿合并，检查点和句末等待任务有数量上限，超限明确停止。设备收音期间始终只显示字幕，不自动播报。

pro 的音频文件仍走原文件链路，支持最多 10 分钟 / 100 MB 的 MP3、WAV、FLAC、OGG；可在“设置 → 阅读与播报”启用文件人声分离。文件不自动播报译音。

数字读音模式需要明确选择金额或逐位号码，只调整合成输入，不改变显示译文；混合语境和重要数字仍需人工核对。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 无法启动或依赖缺失 | 在 PowerShell 使用 README 的模块命令启动，查看报错；确认使用 Python 3.12 x64 和本项目环境 |
| 提示临时缓存不可写 | 在“设置 → 文件位置”清空缓存目录以使用系统临时目录，或选择可写目录，再重新加载 |
| 提示模型不完整 | 检查准备脚本和应用的 `YUEPU_DATA_DIR` 一致，重新准备缺少的组件 |
| 没有收到设备声音 | 检查 Windows 默认输出、来源选择及播放状态；切换设备后重新开始 |
| 没有麦克风输入 | 检查 Windows 麦克风权限和默认输入设备 |
| 回放译音被再次识别 | 交流时使用耳机，避免扬声器声音进入麦克风 |
| 字幕暂时不刷新 | 先检查是否正在回看旧字幕，再查看状态栏的识别与翻译耗时 |
| 歌词大量错词 | 确认选了 pro 及正确方向；可用人声分离处理文件作对照，当前仅有少量歌曲验证 |
| 歌曲模型不完整 | 额外运行 README 的 `song-asr-large` 准备命令；高质量文件处理还需要 `song-separator` |

采集和模型调用失败会显示状态。提交问题时附操作步骤和匿名错误提示即可，不要上传完整私人对话。
