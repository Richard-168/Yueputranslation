# 粤普同传更新日志

## 2026-11-18 · Windows 源码版

短句翻译和实时字幕现在共用一个按需启动的 Hy-MT2 翻译进程。窗口打开即可输入文字。首次收音时再准备识别器，启用自动播报后，在识别出首条原文时开始准备目标音色。

### 收音、字幕与历史

- 正常点击「结束收音」会处理已经收到的音频。持续积压超出缓冲容量时，软件会停止接收新音频、补完队列里的字幕，并在历史和导出中标出从哪里开始缺音。
- 音源就绪后约 3 秒没有交付音频包，界面会显示等待。恢复来包后自动继续，正常交付的静音也能正确识别为设备仍在工作。
- 按 Esc 或关闭窗口时，已完成并送到界面队列的终译和缺音记录会先保存。复制、导出和重开历史会标明尚未核对的旧译稿。手动重播旧稿只朗读已固定的部分。

### 播报与离线使用

- 字幕更新和自动播报可以同时进行。待播内容过多时，字幕继续保存，界面会提示可手动重播。切换会话会停止旧播报，旧设备迟到的报错也不会打断新会话。
- 较长的粤语译音会分句合成，单句仍触及模型上限时会提示。使用扬声器时，可在「首选项 → 常规 → 收音与播报」开启播报期间暂停拾音。该选项默认关闭，开启后与译音重叠的插话也会跳过。
- 系统明确禁止本机服务连接时，文字翻译可自动切换到离线逐句运行的 Hy-MT2。需要本机服务的 pro 语音复核会提示改用 flash。
- 新电脑可双击 `Initialize-YuePu.cmd`，选择文字、基础语音或带 pro 复核三个档位。解压后的模型分别约 1.06、1.96、4.31 GiB，另计 Python 依赖和公共运行库。完整档分批准备，避免超过单次 4 GiB 的上限。已有环境升级时可复用已校验文件。[Windows 初始化和使用说明](windows.md)

### 同机复测

在同一台 Windows 电脑上，用模拟音源输入 3.84 秒合成粤语，经过实际桌面窗口和本地模型。旧版 `4ff19f8` 取三轮中位数，更新后各场景复测一轮。每轮重启应用，保留系统文件缓存。

| 计时范围 | 旧版 | 本次复测 |
| --- | ---: | ---: |
| 测量程序启动到窗口可输入 | 1.63 秒 | 0.92 秒 |
| 提交首条文字到显示译文 | 18.03 秒 | 1.76 秒 |
| 冷开 pro，点击收音到首条原文 | 16.64 秒 | 1.77 秒 |
| 同上，到首条暂定译文 | 18.69 秒 | 3.52 秒 |

延迟 1.5 秒交付最后一包音频时，原先只能保住 512 帧，修复后完整保住 1,024 帧。另一次强制积压测试保住了前 13.632 秒的音频，补出的两条最终字幕和缺音起点均能从历史和导出中找回。两条原先在 16 秒处截断的粤语长句，分句后分别生成 19.28 秒和 20.56 秒，末句波形均与单独合成该段一致。

单独对照准备普通话音色的时机，每种时机各测两个新进程，从首包输入到生成可播放音频的中位数从 16.15 秒缩短至 13.84 秒。计时使用静音输出。自动验证通过 163 项应用测试、18 项安装相关测试、11 项桌面界面检查。

### 已知限制

同一录音中，pro 仍可能把粤语“下晝”识别成“下集”，之后的译文也会继承这个错误。真实麦克风与扬声器的表现、长时间连续收音，以及全新 Windows 安装和卸载仍待实机验证。本次更新提供源码，尚未生成新版 Windows 安装包。
