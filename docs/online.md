# 联网增强（Windows 实验功能）

默认仍为离线模式。联网增强使用阿里云百炼的 `qwen3-asr-flash` 识别和 `qwen-mt-flash` 翻译；译音继续使用本机的普通话／粤语模型。联网是否更准确、实际延迟及稳定性须用自己的音源比较，不能由服务名称推断。

## 开启与使用

1. 按 README 准备基础模型和 `song-asr-large`。本地 pro 段落模型须先就绪，才能在云端失败时继续处理；联网增强不是免下载模型的独立客户端。
2. 在百炼控制台创建自己的 API Key，并开通对应模型。北京和新加坡地域的密钥、权限及计费分别管理，以控制台为准。
3. 打开“设置 → 联网设置…”，选择密钥对应地域，填写 API Key。业务空间 ID 可选。填写后使用对应空间的官方专属域名，留空使用该地域仍受支持的公共域名。不接受任意第三方接口地址。
4. 可点击“测试识别与翻译连接”：只发送 0.25 秒程序生成的静音和“你好”，可能产生少量费用，不打开麦克风。成功仅代表这两个请求获得响应，不评估识别准确性；测试可取消。
5. 勾选“启用联网增强（仅本次运行）”并保存。默认 pro 使用云端复核、粗略翻译与确认后的修正翻译，flash 只使用云端文字翻译。在输入区的“收音选项”中选择麦克风或设备播放声音再开始，也可打开歌曲文件或提交文字。基础离线模型在窗口打开时就会在后台预热，两个翻译方向共用。
6. 联网标识显示“联网待请求”“联网增强”或“本地回退”。悬停可查看本次任务的请求次数、累计提交音频时长（含重叠）与翻译输入字数。计费以服务商账单为准。

关闭联网增强或退出软件后不再为后续任务发送内容。取消处理中请求会结束等待并回收请求进程，但不能撤回已发送的内容或已产生的费用。

## 发送什么、何时发送

- 只有启用后用户发起的任务会调用云端；启动软件、加载本地模型、回看／导出字幕、手动重播译音都不调用云端。
- pro 的轻量草稿只在本地识别；云端复核沿用段落检测的检查点/句末窗口，每次最多提交 30 秒、16 kHz 单声道的内存 WAV。窗口可能包含停顿、背景声音及仍在上下文中的已固定发言；不是只截取文字发生变化的那一瞬间。
- pro 轻量音频草稿不会上传作云端识别，但用于粗译的文字会提交翻译接口；原有检查点/句末复核及文件重叠窗口仍可能重复提交音频。pro 粗译的变化和最终修正均可能重复提交同一部分文字并计费，粗译限频并合并待处理草稿；flash 暂定译文的更新仍可能重复计费。没有自动重试，也不作免费额度或费用上限承诺；请在服务商侧设置可用的额度和提醒。
- 歌曲文件逐窗发送；勾选人声分离时发送处理后的人声音频。不会上传整个原始文件、文件名或本机路径，不使用公开存储链接。
- 同段暂定字幕持续替换原记录；较早稳定内容逐步冻结，句末确认后才生成译音。设备收音期间不播报，避免反馈。
- 云端识别按所选方向提示 `yue` 或 `zh`，翻译支持中英混合输入；异常日／韩文字结果不会直接显示或翻译，会触发本地回退。这不是对底层多语言模型的严格语言限制，也不保证混合英文识别质量。
- 云端识别使用 ASR 返回的标点，不让翻译模型自由改写原文；本地回退保留原有的受约束标点检查。

费用由用户的百炼账户承担，项目不代收。云服务如何留存及处理内容遵循相应服务协议；本软件不作“云端不留存”的承诺。

## 密钥与失败处理

密钥默认只保留在本次进程内存。可选“使用当前 Windows 账户加密记住密钥”，使用 Windows DPAPI 保存至 `%LOCALAPPDATA%/YuePuTranslate/cloud.json`；不存明文密钥，也不保存启用联网的勾选状态。重启后须重新开启。取消“记住”并保存，或“清除密钥并关闭联网”后保存，会删除本机保存的配置。

配置损坏或换 Windows 账户后可能无法解密；应用会继续以离线状态启动，并提示重新输入或清除。不要将密钥、配置文件、个人录音或完整会话发到公开 Issue。

请求设置 3–30 秒超时，默认 8 秒。首次网络异常、权限错误、限额、重定向、无效／截断响应等使**本次任务**切换到本地模型，后续窗口不再请求云端。既有固定原文及译文保留，未确认部分可由本地识别继续修订。只有用户再次开始任务才尝试联网；不是静默反复测试网络。若本地模型本身不可用或失败，会明确报错，不能承诺此时也能完成翻译。

联网请求由独立进程发起，经匿名内存管道接收密钥与内容；只构造受支持地域的固定 HTTPS 地址，不跟随重定向，不读取系统代理、不关闭证书校验。主程序原有 Python 外联拦截仍保持启用；它不是对所有原生进程的 OS 级断网保证。

已增加本地契约及实际子进程／HTTP 模拟服务测试，包括双向请求、上传数据边界、错误分类、拒绝重定向、取消、超时和 Windows 加密存取。模拟服务返回的文字不是云端识别结果，不计入准确率。

当前开发机未配置百炼账户密钥，**真实服务的鉴权、两种模型权限、账号额度、识别／翻译质量及公网延迟尚未验收**。完成配置后，应先测试连接，再用同一短录音对比联网和离线输出；不要把本地模拟通过描述为云服务验收通过。

已使用明确无效的测试凭据向北京正式 HTTPS 接口发送程序测试短句，验证服务返回鉴权错误并回收请求进程；未使用真实账户、未发送私人录音。该负请求不能证明有效密钥调用或模型权限通过。
