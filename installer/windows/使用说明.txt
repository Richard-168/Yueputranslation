粤普同传 Windows 开发预览

安装包内含 Python 3.12 和本地推理运行程序。轻量版首次启动可下载或导入基础模型，
完整离线版已附带模型。准备完成后断网仍可使用离线功能。

安装后从开始菜单打开“粤普同传”，即可输入文字。首次本地翻译加载 Hy-MT2，
后续短句和实时字幕共用这个模型。开始收音时准备识别器，启用自动播报后，在识别出文字时准备目标音色。
持续积压时软件会停收新音频，补完已接收的字幕，并将中断位置记入会话。
在“收音选项”选择音源。麦克风用于面对面交流或手机外放，
“设备播放声音”用于电脑正在播放的视频。
嘈杂环境用“标准”，手机外放、轻声和短句可用“灵敏”。灵敏档更容易收到背景人声。
联网增强默认关闭，启用时需要自己的服务账号密钥，费用由使用者承担。

在「设置 → 模型管理」查看状态，按需获取 pro 复核与文件人声分离模型。
轻量版下载的模型位于 %LOCALAPPDATA%\YuePuTranslate\models，升级和卸载时会保留；
完整离线版随包的模型由 Windows 安装程序管理，位于安装目录 data 中。
如果已经显式配置 YUEPU_DATA_DIR，应用继续使用该目录；一般用户无需设置此变量。
字幕文字会按会话保存在本机，可从左侧历史回看或继续翻译。
需要单独的文本文件时，可手动导出。

从 Windows 设置的“已安装的应用”可卸载。卸载只移除安装器登记的程序和模型，
用户设置、密钥、本地会话历史、导出文件及原有源码和模型保留在原位置。
升级前请先退出程序。此包为未签名开发预览，支持范围和安装验收结果见 Release 说明。

详细使用说明见安装目录 docs/windows.md，联网说明见 docs/online.md。
第三方许可见 docs/THIRD_PARTY.md、docs/licenses、python/LICENSE.txt，
以及 data/models 和 Python 各组件内附的许可。第三方模型仍按其各自许可使用。
普通话译音已更换为 MyShell.ai MeloTTS（MIT）；Kim_Vocal_2 的作者 MIT 许可已留档。
基础识别已改为 WenetSpeech-Yue U2++（Apache-2.0）；旧 SenseVoice 已退出新安装数据。
旧安装包必须重建并重新核验；源码修改不会自动修复既有 EXE／BIN。
Release 的 Corresponding-Sources.zip 保留 Qt 与音频库的对应源码和替换说明，
使用这些第三方组件时仍应遵守各自的许可；本项目不限制修改这些库所需的调试。
